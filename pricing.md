# NitroIDE Pricing

**Free forever — the only plan. There are no paid tiers.**

| | |
|---|---|
| Price | $0 |
| Account | Not required — there are no accounts |
| Paywall | None — every built-in feature is unlocked |
| Code editor | Full Monaco workspace, live preview, HMR |
| Templates | All 12 starter templates included |
| Export | ZIP export, share links, deploy to GitHub Pages / Netlify |

## AI pair programmer (BYOK)

The AI pair programmer is included free and uses **your own provider API key**. NitroIDE charges nothing for AI usage — you pay your provider (if anything) under their terms:

- **Groq** — free tier available
- **Gemini** — free tier available
- **OpenRouter** — free models available
- **OpenAI** — pay-per-use per OpenAI's pricing
- **SambaNova** — per SambaNova's pricing (via a non-storing proxy)

Your API key stays in your browser. NitroIDE never sees it.

## What costs money (not to NitroIDE)

- Nothing on nitroide.com. Optional donations via [Ko-fi](https://ko-fi.com/nitroide) are voluntary.
- If you deploy to Netlify or use a paid AI provider tier, those services bill you directly under their own terms.
