Public Roadmap

Where NitroIDE
Is Going Next.

Every release has one theme and one headline. Here's the road from v26 to NitroIDE 2.0 — dates are targets, the order is the promise.

v26 — Next Up

The Publish Update

One-click deploy. Ship any project to a live URL from inside the IDE — GitHub Pages, Netlify, or Cloudflare — using your own token that never leaves your browser. No build step, no terminal. Target: mid-Oct 2026.

v27 — Planned

The Mobile Update

Touch-first editing. An IDE rebuilt for thumbs: swipeable editor/preview/console tabs, big-type command palette, proper PWA install, and an offline-first project manager. Target: late-Oct 2026.

v28 — Planned

The AI Update

Bring-your-own-key AI. Paste your own model key (free tiers from Gemini, Groq, OpenRouter), and get explain, generate, and fix-from-console right in the editor. Your key and your code never touch our servers — there are none. Target: early-Nov 2026.

v29 — Planned

The Polish Update

Quality before the big one. A deliberate breather: bugfix sweep, performance pass, accessibility to 100, and honest copy over everything new. 2.0 has to feel finished. Target: mid-Nov 2026.

v30 — The Milestone

NitroIDE 2.0

Live sessions + plugins. Real-time collaboration with no backend and no accounts — the host shows a code, the guest pastes it, browsers connect peer-to-peer. Plus a plugin system with a community gallery. Target: late-Nov 2026, with a full public relaunch.

What never changes

No accounts. No logins. No servers seeing your code. Every release — including the AI and deploy features — keeps secrets in your browser. That's the moat, and it's not for sale.
