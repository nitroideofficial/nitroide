Public Roadmap

Where NitroIDE
Is Going Next.

Every release has one theme and one headline. Here's what's already shipped — and what's coming next.

v26 — Shipped

The Creator Backend Update

Self-hosted forms. Contact and feedback now run on our own Cloudflare backend — no third-party form service sees your messages — plus a private admin dashboard with stats, search, and CSV export.

v27 — Shipped

The Mobile Editor Update

Touch-friendly workspace. The command palette moved into the options menu for one-tap access, the PWA install flow got cleaner, and popups stop spilling off-screen on phones.

v28 — Shipped

The Sharing & Templates Update

Find starters, share work. A browsable template gallery with search, filters, and live thumbnails — plus a proper share dialog with X, WhatsApp, and Telegram intents.

v29 — Shipped

The Performance Update

3.5MB lighter. A full vendor and code audit: unused editor languages, localization files, and dead icon weights removed — zero features touched.

v30 — Shipped

The AI Update

Bring-your-own-key AI. Paste your own model key (free tiers from Gemini, Groq, OpenRouter) and get explain, generate, and fix-from-console right in the editor. Your key and your code never touch our servers — there are none. Plus one-click deploy to GitHub Pages and Netlify, and the Ko-fi push.

Next Up — Planned

NitroIDE 2.0

Live sessions + plugins — with a full public relaunch. Real-time collaboration with no backend and no accounts — the host shows a code, the guest pastes it, browsers connect peer-to-peer. Plus a plugin system with a community gallery. The 2.0 milestone gets the big public launch: Product Hunt, Hacker News, and the full announcement circuit.

Later — Planned

Multi-Language Support

Beyond HTML/CSS/JS. TypeScript, Markdown, and JSON editing in the workspace — only languages that run 100% client-side, keeping the no-backend promise.

What never changes

No accounts. No logins. No servers seeing your code. Every release — including the AI and deploy features — keeps secrets in your browser. That's the moat, and it's not for sale.
