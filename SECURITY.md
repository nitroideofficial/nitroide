# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in NitroIDE, please report it privately
by emailing **contactnitroide@gmail.com**. Please include a description of the
issue, steps to reproduce it, and the impact if known.

Please do not open a public GitHub issue for a security vulnerability.
We will acknowledge your report and work on a fix as quickly as possible.

## Scope

NitroIDE is a static frontend web application. It has no backend server of its
own that stores user data — code runs in the visitor's browser, and workspace
data is kept in the browser's local storage unless the user explicitly exports
or shares it. Reports about the hosting platform (GitHub Pages / Cloudflare)
should go to the relevant provider instead.
