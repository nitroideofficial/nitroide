How It Works

From blank tab to running page in four steps.

Step 1 — Open the workspace

One click and you're in — no signup, no installer. A fresh project with index.html, style.css, and script.js is already waiting for you.

Step 2 — Write code

Type in the Monaco editor with Emmet abbreviations, autocomplete, and multi-cursor editing. It feels like VS Code because it runs the same engine.

Step 3 — Watch it update live

Every keystroke re-renders the preview through hot module replacement — no manual refresh, no build step standing between you and the result.

Step 4 — Debug and ship

Log to the integrated console, inject libraries from unpkg with a single command, then export your project as a ZIP when it's ready for the world.

Common Questions

Straight answers before you start typing.

Is it really free? What's the catch?

It's free with no catch hiding underneath: no accounts, no trial timers, no locked features. Your code lives in your browser's local storage, and the project itself is open source.

Where is my code saved?

In your browser's local storage on your own device — nothing is sent to a server. For safekeeping or moving between machines, export the project as a ZIP or push it to GitHub.

Can I use libraries like GSAP, Tailwind, or jQuery?

Yes. Open the developer console inside the workspace and inject any library from unpkg — type > install gsap and it's available to your page instantly, no package manager involved.

Does it work offline?

Yes. NitroIDE is an installable PWA: load it once, and the editor, preview, and your saved projects keep working without a connection.

How is this different from CodePen?

CodePen is built around single pens stored on their servers. NitroIDE gives you multi-file projects, a full VS Code-grade editor, local-first privacy with no account, and one-click export to a real, deployable project.
