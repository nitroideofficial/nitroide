How It Works

From idea to running component in four steps.

Step 1 — Open the React workspace

Launch the playground — no npm install, no create-react-app, no terminal. React 18 is preloaded and ready to render.

Step 2 — Write JSX

Define components with hooks and JSX directly in the editor. Your code is transpiled in the browser in real time as you type.

Step 3 — Add libraries

Need Framer Motion, a charting library, or anything else? Inject it from unpkg with one console command and import it in your component.

Step 4 — Debug and export

Watch state update live with the state visualizer, then export the whole prototype as a ZIP when you're ready to move it into a real codebase.

Common Questions

Straight answers about the React playground.

How does JSX work with no build step?

Your JSX is transpiled directly in the browser as you type, so components render instantly. You skip the entire toolchain — no Babel config, no bundler — which makes it ideal for rapid prototyping.

Which React version is included?

React 18, loaded from CDN. Hooks like useState and useEffect, fragments, and modern JSX conventions all work the way you'd expect.

Can I use hooks and manage component state?

Yes. useState, useEffect, useRef, and custom hooks all run normally, and the built-in state visualizer lets you watch values change as you interact with your UI.

Can I add third-party React libraries?

Yes — inject any package from unpkg through the workspace console (for example, > install framer-motion) and use it in your components right away.

What happens when my prototype outgrows the playground?

Export it as a ZIP and continue in a full toolchain. The playground is built for speed of iteration; nothing about it locks you in.
